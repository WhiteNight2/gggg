# 🍚 오늘 뭐 먹지? - 메뉴 추천기

메뉴를 등록해 두고 버튼 한 번으로 오늘 먹을 메뉴를 무작위로 추천받는 웹 프로그램입니다.
HTML, CSS, JavaScript만 사용했으며 서버, 데이터베이스, 외부 API, 라이브러리가 필요 없습니다.

## 🔗 바로 실행하기

https://WhiteNight2.github.io/gggg/

## 주요 기능

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 기본 메뉴 5개 표시 | 처음 열면 김치찌개, 돈까스, 짜장면, 비빔밥, 치킨이 표시됩니다. |
| 2 | 메뉴 추가 | 입력칸에 메뉴 이름을 쓰고 `추가` 버튼 또는 Enter 키를 누릅니다. |
| 3 | 메뉴 삭제 | 각 메뉴 오른쪽의 `×` 버튼을 누르면 삭제됩니다. |
| 4 | 메뉴 추천 | `메뉴 추천받기` 버튼을 누르면 현재 목록에서 하나가 무작위로 추천됩니다. |
| 5 | 빈 목록 안내 | 메뉴가 하나도 없으면 "메뉴를 등록해 주세요" 안내가 나옵니다. |
| 6 | 입력 검사 | 빈칸이나 이미 있는 이름(앞뒤 공백, 영문 대소문자 차이 무시)은 추가되지 않고 안내 문구가 나옵니다. |

새로고침하면 저장된 내용 없이 처음 메뉴 5개로 돌아갑니다.

## 실행 방법

### 방법 1. 내 컴퓨터에서 실행
1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP` 후 압축 해제, 또는 `git clone`)
2. 폴더 안의 `index.html` 파일을 더블클릭해서 브라우저(Chrome, Edge, Safari 등)로 엽니다.
3. 설치나 서버 실행은 필요 없습니다.

```bash
git clone https://github.com/WhiteNight2/jinwooda.git
cd jinwooda
# index.html을 브라우저로 열기
```

### 방법 2. GitHub Pages로 실행
1. 저장소의 `Settings` → `Pages`에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
2. 1~2분 뒤 안내되는 주소로 접속합니다.

## 사용 방법

1. **메뉴 추가**: 입력칸에 먹고 싶은 메뉴를 쓰고 `추가`를 누릅니다.
2. **메뉴 삭제**: 목록에서 지우고 싶은 메뉴의 `×`를 누릅니다.
3. **메뉴 추천**: `메뉴 추천받기`를 누르면 잠깐 메뉴가 섞이다가 하나가 결정됩니다. 마음에 안 들면 `다시 추천받기`를 누르세요. (메뉴가 2개 이상이면 직전과 다른 메뉴가 나옵니다.)
4. **메뉴가 없을 때**: 안내 문구에 따라 메뉴를 먼저 등록하세요.
5. **초기화**: 브라우저를 새로고침하면 처음 상태로 돌아갑니다.
